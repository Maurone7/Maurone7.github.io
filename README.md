# Maurone7.github.io

Personal website of Mauro Patimo — Ph.D. student in Aerospace Engineering at Penn State.

Plain HTML/CSS/JS, served by GitHub Pages. No build step.

## Adding media
- **System video:** save as `assets/video/system.mp4` (H.264 MP4, keep under ~50 MB; GitHub rejects files over 100 MB).
- **3D model:** save as `assets/models/system.glb` (glTF binary). Until each file exists, the page shows a "coming soon" placeholder.

## Preview locally
    python3 -m http.server 8000   # then open http://localhost:8000
